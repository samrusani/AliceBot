# Archived Build-Process Artifacts

This folder preserves historical build-process artifacts: internal status summaries, phase and sprint specs, planning packets, closeout reports, launch checklists, and point-in-time build/review reports.

These documents describe how earlier versions of Alice were planned and shipped. They are kept for provenance and history only:

- They are not product documentation.
- They do not describe current behavior, scope, or roadmap.
- Internal links inside these files may be stale; they were written against older repo layouts.

For current documentation, start at the repository [README](../../../README.md) and [docs/alpha/quickstart.md](../../alpha/quickstart.md).
