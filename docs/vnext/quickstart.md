# Quickstart (Pointer)

The canonical setup walkthrough lives at [docs/alpha/quickstart.md](../alpha/quickstart.md).

Short version:

```bash
git clone https://github.com/samrusani/AliceMemory.git
cd AliceMemory
make setup
make migrate
make doctor
make dev
```

Then open `http://localhost:3000/vnext`.
