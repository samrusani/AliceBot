# Alice v0.10.2 Release Notes
<!-- alice-release-state: {"schema_version":"alice_release_document_state_v1","version":"0.10.2","publication_status":"pending","checksums_status":"pending"} -->

`v0.10.2` is a security, reliability, and quality release. It supersedes the
tagged-but-unpublished `v0.10.1` candidate, whose PyPI publish workflow failed
closed on a step-ordering bug (release dependencies were installed after the
step that validates the semantic-eval attestation, so `release_check` could not
import `alicebot_api`). No artifacts were ever published for `v0.10.1`. All of
its remediation is carried forward here.

## Fix in this release

- **Publish workflow ordering.** The PyPI publish job now installs the package
  before the release-check steps that import first-party modules, so the
  credential-free semantic-eval attestation validation runs against the
  installed package instead of failing to import it.

## Carried forward from v0.10.1 / v0.10.0

The full third-audit remediation and its semantic-gate fix: business/money
queries stay in vector retrieval (no implicit hard `personal`-domain filter);
the semantic release gate applies each suite's declared aggregate targets while
remaining fail-closed on skips, missing vector participation, malformed
evidence, and failed targets; one signed-vector write contract across the eval
seeder and both backfill paths; scope/status/domain/sensitivity-aware atomic
capture dedupe (migration `0085`); people/time predicates pushed into the store
with bulk entity-edge resolution; fail-closed lifecycle cycle detection with 3+
duplicate-pointer repair (migration `0086`; `0084` unchanged); authoritative
roll-up totals; iterative HNSW scan on filtered vector search; and the P2
backlog (pgvector 0.8+ enforcement, import/backup hardening, web decomposition
with browser/a11y/coverage gates, zero-error web typecheck, clean first-party
mypy, portable packaged-README links, structured exact-SHA release-control
attestation).

## Upgrade

`alembic upgrade head` applies migrations `0085` and `0086` (idempotent; safe
downgrades). After upgrade, run `alicebot vnext memories backfill-embeddings` to
re-embed existing vectors under the endpoint-aware v2 signature; those vectors
are retrievable. No other operator action is required.

## Verifying this release

Alice publishes to PyPI through GitHub Trusted Publishing. Once published, the
wheel and source distribution carry PyPI's integrity attestations, which bind
each file to this repository, the release tag, the publishing workflow, the
exact commit, the release event, and the protected `pypi` environment —
verifiable on the project's PyPI page. Their exact SHA-256 digests will be
recorded in `docs/release/v0.10.2-checksums.txt` in this repository as part of
the post-publication commit.
